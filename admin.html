Armazenamento

  1. Preencha .env com o URL e a chave publishable do projeto Supabase e execute node scripts/build-env.mjs.
  2. No Supabase, abra SQL Editor, cole o conteúdo de supabase/schema.sql e carregue em Run.
  3. Em Authentication → Users → Add user, crie o utilizador do administrador (marque Auto Confirm User).
  4. No SQL Editor, execute a linha final do ficheiro com o email desse utilizador, para o tornar administrador.
  5. Publique o site e entre neste painel com esse email e palavra-passe.

Cópia de segurança

Descarregue todos os dados (marcações, preços, contactos) num ficheiro, ou reponha a partir de uma cópia.
